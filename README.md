# seismology_HW11_final_report
# 🌍 地震學期末報告時間軸網頁 (Seismology Course Timeline)

這是一個專為**地震學課程**設計的互動式網頁時間軸，用以整合並呈現整學期的學習進度、實驗成果與精選報告網址。

為了完美契合學科特色，網頁內特別運用純 CSS 與 JavaScript 研發了**「地震震動、螢幕裂縫與平移斷層錯動」**的轉場動畫特效。

---

## 🚀 特色功能

* **互動式數線時間軸**：採用響應式（RWD）垂直數線設計，節點以震央圖示呈現，清晰梳理學期進度。
* **斷層破裂轉場特效**：點擊任何附有連結的日期時，會觸發以下動態視覺效果：
    1.  **地動山搖（Shake Effect）**：整個畫面開始劇烈震動，模擬地震波（S波）抵達時的強烈震感。
    2.  **地表破裂（Surface Rupture）**：螢幕中央瞬間撕裂，噴發出象徵岩漿的熾熱紅光裂縫。
    3.  **平移斷層滑動（Strike-Slip Faulting）**：兩塊岩石地殼面板分別往左下與右上向外劇烈滑開，隨後平滑切換至目標網頁。
* **自適應網頁設計 (RWD)**：完美相容於電腦、平板與手機等不同螢幕尺寸。

## 🛠️ 使用技術

* **HTML5**：構建結構化、語意化的時間軸。
* **CSS3**：
    * 利用 `clip-path` 的多邊形遮罩功能，手工繪製出不規則的「地殼邊緣」鋸齒形狀。
    * 透過 `@keyframes` 動態模擬震動（Shake）與斷層平移（Fault Displacement）的真實物理錯動感。
* **Vanilla JavaScript**：精準控制事件監聽、震波延遲跳轉（2.8秒動畫時間）與動態 Class 的寫入。
